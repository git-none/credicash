# Backend 1.1.20 - Expediente documental

El expediente administrativo/contable incorpora `verifications`, con el historial de verificaciones documentales del usuario.

El escritorio utiliza estas rutas de archivos para mostrar:
- documento frontal;
- documento posterior / RIF;
- selfie;
- estado de la verificación;
- fecha de carga.

El cambio amplía la respuesta existente y mantiene compatibilidad con clientes que ignoran el nuevo campo.
